# 🛒 MyShop - Full Stack E-Commerce System

A complete e-commerce web application built with **Laravel**, **PHP**, **MySQL**, and **Blade** templating. Developed independently over 6 months.

---

## 🚀 Features

### 🛍️ Customer Side
- Product listing with image gallery & thumbnails
- Color picker (20+ colors in Arabic)
- Product rating & review system
- Search bar & breadcrumb navigation
- Flash sales with countdown timer
- Discount badges
- Shopping cart & checkout (Cash on Delivery)
- Order history with expiry timer
- Wishlist
- Account settings (personal info, password, addresses)
- Contact page with Google Maps integration

### ⚙️ Admin Dashboard
- Products CRUD (Create, Read, Update, Delete)
- Orders management (Approve / Reject / Contact Customer)
- Customer complaints management
- Video management (Video Galaxy page)
- Dashboard overview with statistics
